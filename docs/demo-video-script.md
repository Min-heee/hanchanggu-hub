# 시연 영상 대본 (약 3분 10초)

보는 사람은 병원 채용 담당자입니다. 코드는 보여 주지 않고, **상담실장의 하루가 어떻게 줄어드는지**만 보여 줍니다.
장면마다 가운데 칸은 화면에서 할 일, 오른쪽 칸은 말할 내용입니다. 말은 그대로 읽지 않아도 됩니다.

## 녹화 전 준비 (10분)

1. Ollama를 켜고(`ollama serve`) `.env`의 `INQUIRY_HUB_LLM=local`로 서버를 켭니다.
2. 브라우저 창을 1440×900 정도로 맞추고, 북마크바·알림을 숨깁니다.
3. 화면 오른쪽 위 **초기화**를 누르고, 문의 6건이 모두 '초안 준비'가 될 때까지 기다립니다(로컬 AI로 4~5분).
4. 녹화는 macOS `Cmd+Shift+5` → '선택 부분 기록', 옵션에서 마이크를 켭니다.
5. 데모 날짜는 녹화하는 날 기준으로 다시 계산됩니다. 대사에 날짜를 넣지 말고 '내일', '이틀째'처럼 말하세요.
6. 로컬 AI 초안은 실행할 때마다 문장이 조금씩 다릅니다. 녹화 전에 장면에 나오는 초안을 한 번씩 읽어 두세요.

**편집 팁**: '새 문의 가져오기' 뒤 초안을 만드는 동안(1건에 40초 안팎)은 잘라 냅니다. 잘린 자리에 "로컬 AI가 초안을 만드는 동안은 줄였습니다" 자막을 한 줄 넣으면 정직하게 보입니다.

## 장면

| 시간 | 화면에서 할 일 | 말할 내용 |
|---|---|---|
| 0:00–0:15 | 문의함 첫 화면을 그대로 보여 줌 | 성형외과 상담실장은 카카오톡, 네이버 톡톡, 인스타그램, 홈페이지 문의를 따로 열어 답하고, 답한 내용을 CRM에 다시 적습니다. 한창구는 병원 CRM은 그대로 두고 옆에 붙어서, 이 일을 한 화면으로 줄이는 AI 도구입니다. 나오는 병원과 고객은 모두 가상입니다. |
| 0:15–0:35 | 맨 위 **박서연** 클릭 → 빨간 응급 안내 → 오른쪽 CRM의 수술 이력 | 수술 이틀째인데 코피가 멈추지 않고 열이 38.4도라는 문의입니다. 응급일 수 있어서 '긴급'으로 맨 위에 올라왔습니다. 응급 문의는 AI를 거치지 않고, 병원이 정해 둔 안내 문구로 초안을 만듭니다. 오른쪽에는 CRM의 수술 이력이 같이 뜹니다. |
| 0:35–1:00 | **이민호** 클릭 → 초안의 실밥 제거 부분 → 오른쪽 CRM의 내일 예약 → 'AI에 보낸 내용 보기' 펼치기 | 이 고객은 눈 수술 7일째이고, 내일 실밥 제거 예약이 있습니다. AI가 CRM에서 이 일정을 읽어 초안에 넣었습니다(초안에 일정이 빠졌으면 녹화 전에 '다시 생성'). AI에는 이름과 연락처를 가린 내용만 보내고, 무엇을 보냈는지 여기서 그대로 확인할 수 있습니다. |
| 1:00–1:20 | **새 문의 가져오기** → (편집: 초안 만드는 시간 자르기) → **김지수** 클릭 → **Mika** 클릭 | 새 문의가 들어왔습니다. 김지수 고객은 인스타그램 DM과 카카오톡으로 따로 물어봤는데, 같은 사람이라서 한 대화로 묶였습니다. 일본어 문의에는 일본어로 초안을 쓰고, 한국어 번역을 같이 보여 줍니다. |
| 1:20–1:35 | 아무 초안 끝에 `부작용 없이 100% 만족하실 거예요` 입력 → 경고 확인 → 지우기 | 의료광고에서 문제가 될 수 있는 표현은 쓰는 즉시 경고합니다. 효과를 보장하거나 부작용을 부정하는 말입니다. |
| 1:35–1:55 | **정다은** 클릭 → (노란 'AI 초안 검토' 경고가 있으면 보여 주고 고침) → **승인하고 발송** → 오른쪽 CRM에 새 고객 번호(`L001`)와 응대 기록, 위쪽 '초안 유지율' | 로컬 AI는 가끔 실수를 해서, 실제로 돌려 보며 찾은 실수 유형은 자동으로 경고합니다. 승인하면 채널로 나가고(데모에서는 보낸 기록만 남깁니다), CRM에 응대 기록이 남습니다. 처음 문의한 분은 새 고객으로 등록됩니다. 위의 '초안 유지율'은 AI 초안이 얼마나 그대로 쓰였는지 보여 줍니다. |
| 1:55–2:25 | **리콜·팔로업** 탭 → 첫 카드(수술 다음날 안부) → **정보성 알림 일괄 승인** → 아래 '보내지 않는 대상' | CRM의 수술·예약 날짜로 오늘 연락할 사람을 찾았습니다. 수술 다음날 안부나 예약 전날 안내는 알림톡이라, 미리 검수받은 문구에 이름·시술·날짜 같은 값만 바꿔 넣어서 한 번에 승인합니다. 광고성 메시지는 수신 동의가 없거나 답하지 않은 문의가 있으면 보내지 않고, 이유를 아래에 남깁니다. |
| 2:25–2:50 | **문의함** 탭 → **새 문의 가져오기** → **오세린** 클릭 → '수신거부 요청' 표시, 오른쪽 '광고 수신: 동의 안 함'과 수신 동의 이력 → 초안 속 처리 결과 안내 문단 → **리콜·팔로업** 탭 아래 '보내지 않는 대상'의 오세린 '수신거부 반영' | 고객이 답장으로 수신거부를 요청했습니다. 들어오는 순간 CRM의 광고 수신 동의를 끄고, 법으로 정해진 처리 결과 안내는 초안에 코드가 넣습니다. 리콜 탭을 보면 이 고객에게 나갈 예정이던 광고가 이유와 함께 멈춰 있습니다. |
| 2:50–3:05 | 문의함으로 돌아와 전체 화면 | AI는 초안만 쓰고, 보내는 결정은 사람이 합니다. 병원 컴퓨터에서 도는 무료 AI라 AI 사용료가 없고, 환자 문의를 외부 AI 회사로 보내지 않습니다. 아직 실제 채널과 CRM에는 연결하지 않았습니다. 실제 병원에서는 CRM 연결 방식부터 확인하고, 실제 문의로 품질을 재면서 시작하겠습니다. |

**오세린 장면 주의**: 로컬 AI가 수신거부한 고객에게 "상담은 언제 가능하시나요?"처럼 다시 권하는 문장을 쓴 적이 있습니다. 녹화 전에 초안을 읽고, 그런 문장이 있으면 지우는 모습을 보여 주거나 '다시 생성'을 누르세요. 지우는 모습을 보여 주면 "그래서 사람이 마지막에 봅니다"라고 한 줄 덧붙이면 됩니다.
